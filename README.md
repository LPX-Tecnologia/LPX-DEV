# LPX Dev – Sistema de Orçamento e Vendas de Serviços

Sistema completo para oferecer serviços de desenvolvimento com chatbot, orçamento automático, aceite de contrato, pagamento PIX (simulado) e painel administrativo.

## Funcionalidades

- Chatbot interativo para orçamento
- Cálculo automático de valores
- Aceite de termos de contrato
- Geração de PIX (copia e cola)
- Armazenamento de pedidos no localStorage
- Painel do desenvolvedor com login
- Status dos pedidos (pendente, em produção, concluído)

## Como usar

1. Altere a senha do admin no arquivo `js/main.js` (constante `SENHA_CORRETA`).
2. Substitua a chave PIX no arquivo `js/chatbot.js` (variável `CHAVE_PIX`).
3. Faça o deploy no GitHub Pages.
4. Acesse `index.html` para o site e `admin.html` para o painel.

## Personalização

- Edite textos e imagens nos HTMLs.
- Altere cores no `style.css`.
- Ajuste os valores dos serviços em `js/chatbot.js`.
